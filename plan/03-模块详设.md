# 03 · 模块详设

> 本文定**契约**（字段名、id 词表、排序、退出码、fingerprint）与**各模块的实现要点**。
> 数值口径只在 `data/README.md` §8 定义；本文所有阈值以**口径键名**引用，不写数字。
> M0 已落地的部分标 ✅，其余按里程碑落位。

## 一、通用契约（全模块共用）

### 1.1 Finding（`report/model.py`）

```python
@dataclass(frozen=True)
class Finding:
    id: str                    # 稳定标识符（词表见 §1.2）
    module: str                # "M1" | "M2" | "M3" | "M4" | "M5"
    severity: str              # "ok" | "info" | "warn" | "error"
    observed: str              # 观测值的定点字符串
    threshold: str | None      # 阈值；engineering-heuristic 可给口径键名
    threshold_status: str      # "verified" | "unverified" | "not-applicable"
    basis: str                 # "gen-spec" | "engineering-heuristic" | "official-dictionary" | "vector"
    evidence: dict             # {"kind","ref","quote"}
    fix: dict | None           # warn/error 必填（§1.4）
    target: str                # canonical_target，参与 fingerprint
    ai_position: int           # 元素串内位置；非 GS1 场景为 -1
```

**不可变**：`frozen=True`。渲染层只读，无法就地"修"结论。

### 1.3 排序与分组

`findings` 输出顺序固定为 `(module, ai_position, id)` 字典序。
**不用**"严重级别优先"：级别会随阈值状态变化，排序跟着变会让两次 run 的 diff 全是噪音。

### 1.4 `fix` 契约

`severity ∈ {warn, error}` ⇒ `fix` 非空，且必须含 `kind` + 以下二者之一：

- `to` + `unit`（目标数值），或
- `min_delta` + `unit`（最小增量方向）。

`fix` 只描述**参数要变成什么**，绝不生成图像、不改输入文件（`plan/00` 弃选项"自动修图"）。
无 `fix` 的 warn/error 由 `tests/test_fix_contract.py` 判红。

### 1.5 fingerprint（`report/model.py`）

```
fingerprint = sha256(f"{id}\x1f{module}\x1f{target}").hexdigest()[:16]
```

不含时间戳 / 路径 / 机器名 / severity。**含 severity 会让"阈值状态一改，指纹全变"**，
破坏跨 run diff。

## 二、CLI 契约（`src/bpreflight/cli.py`）✅ M0 已落

```
bpreflight check  --input <spec.json> [--fail-on none|warn|error] [--strict-thresholds]
                  [--json] [--md] [--with-timestamp]
bpreflight report --input <spec.json> --format json|md   # 单独取一种格式到 stdout
bpreflight oracle --input <spec.json>                     # M5，可选；落点固定 out/
```

| 旗标 | 语义 | 纪律 |
| --- | --- | --- |
| `--fail-on` | 门槛，默认 `none` | 三档 × 最严重级别 = 9 格，逐格测试（M4） |
| `--strict-thresholds` | `unverified` 项恢复 `error` | 报告首屏打 `THRESHOLDS: unverified (<key>)` |
| `--json` / `--md` | **开关**（非路径） | 写固定 `out/report.json` / `out/report.md`（D20）；`out/` 必须已存在，否则 exit 3 |
| `--with-timestamp` | 报告头 `deterministic: false` | 默认不读时钟 |
| `--input` | 参数/规格文件 | **只收 JSON**（D14）；扩展名不符 exit 3，不做内容嗅探 |

**输出落点合同（D20）**：落点由模块级常量拼出（`OUT_DIR` / `JSON_REPORT` / `MD_REPORT` /
`ORACLE_JSON` / `ORACLE_MD`），**不含任何来自 argv 的成分**；`argv` 只决定"写不写"。
默认只打 stdout，CI 用重定向即可（`bpreflight check --input spec.json > out/report.json`）。
判据：`tests/test_cli_contract.py::test_report_paths_are_not_configurable` 断言
`--json <path>` 直接是 argparse 用法错误 —— 有人把开关改回取值式，这条立刻红。

**参数语义纪律**（`references/delivery.md` CLI 四条）：

1. **不写 `args.x or DEFAULT`**：`--fail-on` 用 `choices`，其余用 `None` 哨兵，
   显式判 `is None`。
2. `--input` 给了但读不到 ⇒ **exit 3 并点名"不回退到任何内置样例"**。
3. 未知 `--format` ⇒ exit 3 并列出支持面（`json|md`）。
4. 中间产物全落固定 `out/`（`oracle` 子命令），可单步复查；落点不含 argv 成分（D20）。

## 三、M1 · 数据层（`src/bpreflight/gs1/`）

| 文件 | 职责 | 要点 |
| --- | --- | --- |
| `checksum.py` | **全仓唯一**的 `gs1_check_digit()` | 严格按 §8.1；`grep -rc "def gs1_check_digit" src/` == 1 |
| `dictionary.py` | 读内嵌字典 → `AIDef` 对象 | 解析 `req`/`ex`/`csum`/`yymmd0`/`N`/`X`/`*`/`?`；**不实现语义规则**，只把字典行变成数据 |
| `elements.py` | 元素串 → `elements[]` | 支持 `(01)…(10)…` 与 FNC1 原生串两种形态 |
| `validators.py` | 四个语义解释器 + 长度/字符集/日期 | `req` 的 OR/AND、`ex`、`yymmd0`、`csum` |

**`yymmd0` 实现纪律**：`DD=00` 合法 → 产出 `dd00_last_day_of_month`（info）并把值归一为**当月最后一天**
（用 `calendar.monthrange`，不手写闰年）。对照用例 `(17)251301` 必须 `invalid_date`。
两条一起才证明"特例"没被实现成"日期校验全关"。

**字典哈希**：`src/bpreflight/data/vectors/dict_manifest.json` 记 `{path, sha256, dict_version}`；
报告头带 `dict_version` 与 `dict_sha256`，可独立复算。

## 四、M2 · 符号层（`src/bpreflight/symbols/`）

- `profiles.py`：读 `src/bpreflight/data/vectors/symbol_profiles.json`。**容量/字符集/模式规则都是数据**，
  代码只做"字符集 ⊆ / 长度 ∈ / 模式可覆盖"三段判定。
- `feasibility.py`：产出 `encoding_plan = {symbol, mode, segments[], total_modules, checksum}`。
  切分唯一性靠**固定优先级 longest-first**，并落 `tie_break: "longest-first"`。
- 校验位**不复制**：一律调 `gs1/checksum.py`。

## 五、M3 · 印刷层（`src/bpreflight/print/`）

| 文件 | 检查 | 输入 | 关键纪律 |
| --- | --- | --- | --- |
| `quiet_zone.py` | C1 | `quiet_zone_mm` × 4 侧、`x_dimension_mm` | **结构档 `== 0` 恒 error**，不读任何阈值 |
| `magnification.py` | C2 | `x_dimension_mm`、`gen_spec.nominal_x_mm` | 边界：`0.2640`/`0.6600` 不报，`0.2639`/`0.6601` 报 |
| `raster.py` | C3 | `x_dimension_mm`、`target_dpi` | 工程判据，**不参与未核降级**；边界 `1.4999/1.5000/1.9999/2.0000` |
| `bar_height.py` | C4 | `bar_height_mm`、`x_dimension_mm` | 模块比 vs 符号阈值 |
| `color.py` | C5 | `bar_color`、`space_color`、`illumination` | 两项判据**不合并**；红条+红光 → collapse，红条+白光 → 走亮度 |

**阈值装载单点**：`print/thresholds.py` 是唯一读 `src/bpreflight/data/vectors/*.json` 的地方；
判定模块**接收已装载对象**，不自己读文件（这是"阈值零硬编码门"能成立的结构前提）。

**缺参即拒判**（`data/README.md` §8.9 G3）：缺 `x_dimension_mm` ⇒ 只产 `input_incomplete`，
**不产**任何 `quiet_zone_*` / `magnification_*` / `raster_*` 结论。测试断言"该输入下这些 id 一个都不出现"。

## 六、M4 · 报告与门禁（`src/bpreflight/report/`）✅ M0 已落骨架

| 文件 | 职责 |
| --- | --- |
| `model.py` | `Finding` / `Report` / `fingerprint` / 排序 / `summary` 派生 |
| `render_json.py` | `json.dumps(..., sort_keys=True, ensure_ascii=False, indent=2)` + 尾部换行 |
| `render_md.py` | 首屏三段字面固定，随后分组明细 |

**首屏三段字面（顺序与措辞固定，测试断言字面）**：

```
VERDICT: <pass|warn|fail>
FINDINGS: ok=<n> info=<n> warn=<n> error=<n>
TOP FIX: <最重要一条 fix 的单行摘要，无则 none>
```

**verdict 派生**（`severity.py`）：无 warn/error → `pass`；有 warn 无 error → `warn`；有 error → `fail`。
不设第四值（§8.8）。

## 七、M5 · 回读（`src/bpreflight/oracle/`，可选）

- `sampler.py`：**纯函数**，`(plan, x_mm, dpi, colors) → 灰度位图 bytes`。无随机、无抗锯齿。
- `zxing.py`：外部引擎探测（`shutil.which` + 子进程）。缺失 ⇒ `skipped: "oracle_absent"`。
- `agreement` ∈ {`consistent`, `m3_stricter`, `m3_laxer`}；`m3_laxer` 记为 bug（`plan/00` D10）。
- **不改 M3 判定**：M5 只追加 `oracle` 段。

## 八、错误与退出码（`src/bpreflight/exitcodes.py`）✅ M0 已落

单一实现点，纯函数：

```python
def exit_code(*, fail_on, worst_severity, usage_error=False) -> int
```

优先级：`usage_error → 3`；否则按 §8.5 矩阵（`none` 永 0；`warn` 档跨门槛返 1/2；未跨门槛返 0）。
**`3` 不参与判定计数**：用法错误 / 输入不可解析 / 内嵌字典缺失三种都走它。
