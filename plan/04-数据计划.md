## 二、真值纪律（本项目四条）

1. **真值的字节不依赖"跑生成器那台机器的工具链版本"**。
   本项目的真值只有两类：①**官方向量**（字典原文 + 官方单测，字节由上游给）；②**本工具定义的
   工程判据**（输入 + 期望，期望可由输入独立复算）。**不**用"某版本渲染器产出某图像哈希"
   这类会随工具链漂移的真值。M5 的 oracle 结果**不入真值**，只作对照（`skipped` 可缺席）。
2. **真值只存输入与期望，期望值可由输入独立复算**。
   `gs1_vectors.json` 里每条存 `data_digits` + `expected_check_digit`，测试**重新算一遍**再比，
   不把"算出来的字符串"当不变量抄进去。
3. **抽样得出的判据必须全量复核**。
   字典语义（`req`/`ex`）不是"抽样 8 行就对"——M1 落库时必须对**整张字典**做一次结构校验
   （每行都能解析成 `AIDef`，无未识别记号），并把"解析了多少行"打进测试结论（非空跑自证）。
   ✅ **M1 已做到**：`tests/test_gs1_semantics.py` 逐条断言
   **344 行 / 224 条目 → 541 个具体 AI / 283 组件 / req 193 / ex 85**，并把这段计数打印进测试输出。
4. **注释不是真值**。
   字典行尾 `# SSCC` 这类注释只用于人读；断言取**字段值**（`N18,csum,gcppos2`），
   不取注释文字（`references/delivery.md` 语料注释条）。

## 三、阈值三态与"未核"的处置

每个阈值项在 JSON 里长这样：

```json
{
  "modules_min": {"value": 7, "source": "<GenSpec 表号/URL>", "status": "unverified",
                  "verified_at": null, "basis": "gen-spec"}
}
```

| 字段 | 纪律 |
| --- | --- |
| `value` | 占位默认值。**文档与报告不得把它写成规范要求** |
| `source` | 必须指得出（表号/URL/文件行）。指不出就删掉该项，不留无主阈值 |
| `status` | `verified` / `unverified`。**只有真核过 GenSpec 原表才允许写 verified** |
| `verified_at` | `verified` 时必填 ISO 日期；`unverified` 时必须为 `null` |
| `basis` | `gen-spec`（参与未核降级）或 `engineering-heuristic`（**永不降级**） |

**降级规则**（`data/README.md` §8.2）：`status != verified` ⇒ `severity` 降为 `warn` 且
`threshold_status: "unverified"`；`--strict-thresholds` 时恢复 `error` 并在首屏标注。
`engineering-heuristic` 项无 `status` 字段，`threshold_status` 恒 `not-applicable`。

## 四、数值口径的唯一引用方式

- 代码与文档**只引用口径键名**：`quiet_zone.modules_min`、`gen_spec.nominal_x_mm`、
  `magnification.range`、`raster.dots_per_module`、`contrast.min_ratio`、`exit_codes`。
- **禁止**在 `src/` 出现裸阈值字面量（`tools/check_thresholds.py` 静态扫，0 命中才过）。
- 改口径的顺序固定：**改 `data/README.md` §8 → 同提交改 `src/bpreflight/data/vectors/*.json` → 再改代码与测试**。

## 五、数据生成与冻结

| 环节 | 做法 |
| --- | --- |
| 生成 | `tools/gen_fixtures.py`：确定性、无网络、无随机、不读时钟 |
| 冻结 | `fixtures/manifest.json` 记每件 `sha256` + 生成参数；`--check` 位级比对 |
| 归仓 | 产物（`fixtures/*.json` 的实际内容）**不入仓**；入仓的是**生成器 + 清单 + 向量** |
| 复生成 | 任何人 `py -3.12 tools/gen_fixtures.py --check` 必须 0 差异 |

**"部分运行不得改写全集清单"**：`gen_fixtures.py --suite A` 只写 A 的条目，
`manifest.json` 里的其余条目必须原样保留（`references/planning-and-data.md` 生成器纪律）。

| # | 缺口 | 影响 | 处置 |

**这些缺口不阻塞 M1/M2**：M1 的基座是**官方向量**（可靠），M2 的结构判定只用"字符集/长度/模式"
这类由数据文件表达的规则（可随后续核对收紧）。
