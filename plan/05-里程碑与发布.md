## 五、风险登记（提前识别，别到发布期才想）

| 风险 | 影响 | 缓解 |
| --- | --- | --- |
| 未核阈值被读者当成标准 | 声誉 / 误用 | 三态字段 + 首屏 `THRESHOLDS: unverified` + 门禁降级 + 文档凡引用必带 ⚠️ |
| 骨架期"没有 findings ⇒ pass" | 工具说谎 | `implementation_pending` 强制 error，M1 同提交退役 |
| 报告层长出第二套判定 | 两套答案 | 渲染层零判定 AST 守门 + 只依赖 `report.model` |
| 阈值散落成字面量 | 改一处漏一处 | `tools/check_thresholds.py` 常驻门 + 装载单点 `print/thresholds.py` |
| 3.9+ 语法混入（本机 3.8 是 CI 之外的通道） | 3.8 用户直接 SyntaxError | `tools/check_python_floor.py` AST 扫全仓（含 `tests/`） |
| 无远端期间谎报 CI 绿 | 发布期以为验过 | 状态表与 DoD 只写"本地等价校验（未接远端）"；M6 补记 |
| 数值口径两份（plan/01 与 data/README） | 冲突 | 口径只在 `data/README.md` §8；plan 只引用键名 |
| Windows 控制台编码 | 中文输出乱码 | 脚本一律 `-X utf8`；README 写清 |
