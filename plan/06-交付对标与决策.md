## 四、决策补充（延续 `plan/00` §二编号）

| # | 日期 | 决策 | 结论与理由 |
| --- | --- | --- | --- |
| D14 | 2026-10-27 | **首期输入格式只收 JSON** | `tomllib` 是 3.11+，而 `requires-python >= 3.8`；为 TOML 引第三方库违反零依赖红线。**扩展名不符即 exit 3，不做内容嗅探**（`references/delivery.md` 格式按声明分派）。TOML 列二期（自带最小解析器，或抬升下限到 3.11）。 |
| D15 | 2026-10-27 | **许可证 = Apache-2.0**（D7 落定） | 与内嵌 `gs1-syntax-dictionary` 同许可，NOTICE/归属最简单；含专利授权条款。`src/bpreflight/data/` 下随附上游 LICENSE 与来源哈希。 |
| D16 | 2026-10-27 | **`requires-python = ">=3.8"`，并由 AST 门守** | 本机实测可用解释器为 3.8.8（`py -3.8`）与 3.12.10（`py -3.12`）；`python` 是商店占位符。下限取 3.8 以覆盖更宽的用户面，代价是新语法禁用 → `tools/check_python_floor.py` 常驻扫 `src/` 与 `tests/`。 |
| D17 | 2026-10-27 | **骨架期用 `implementation_pending` 而非空 findings** | 空 findings 会派生 `verdict: pass`，等于"工具说这个条码没问题"——而它还没做任何判定。用一条 `error` 级 finding 让骨架**必然 fail**，M1 落地同提交退役（`plan/03` §二）。**✅ 2026-10-27 已履行**：退役并换成"该 id 不再出现 + `pass` 只在真有判定时可能"（`plan/00` D16 兑现记录）。 |
| D18 | 2026-10-27 | **CI 五门为独立 step，且必须含布局门与脱敏门** | 门只在开发机存在等于没有（`references/methodology-binding.md` ②.6）。CI 里五条 step + pytest 双版本矩阵。**M1 修订**：新增第六道门 `check_ci_workflow.py`（`plan/00` D23）并同样注册为独立 step——"每条门一个 step"这条判据从此**由机器守**（`CI.GATES`），不再靠人抄。 |
| D19 | 2026-10-27 | **本轮不建远端、不推送** | 用户明示"先写好计划、部署骨架，不着急直接开始"。所有 CI 类结论一律写"本地等价校验（未接远端，CI 待首推验证）"，M6 补记真实 run。 |
| D20 | 2026-10-27 | **输出落点不是参数：固定写 `out/`** | `--json` / `--md` 是**开关**（不是路径），写固定 `out/report.json` / `out/report.md`；`oracle` 写 `out/oracle-report.{json,md}`。落点由模块级常量拼出，**不含任何 argv 成分**；`argv` 只决定"写不写"。默认仍只打 stdout（CI 用重定向）。`out/` 必须已存在，否则 exit 3 且零副作用。理由：① 报告按设计不含用户主目录绝对路径（`data/README.md` §8.7），输出面同样固定；② 用法就是"在项目目录里跑、把报告放进项目的 `out/`"；③ **先试过"限定 cwd 内相对路径 + 白名单 + realpath 归一 + 非链接"这一档，Mimosa 提交门仍报** argv→`open()` 的静态污点链——该判据认的是"链存不存在"，不是"路径安不安全"，继续加校验只会改变行号。因此按"契约收缩"而非"措辞回避"处理，并把该判定如实登记进发布留档。代价：不能自选输出文件名——`tests/test_cli_contract.py`（含 `test_report_paths_are_not_configurable`）与 README 已同步。 |
| D21 | 2026-10-27 | **M1 三条落地口径** | ① **字典/向量装载失败 = exit 3**（§8.5 第三类 `3`），不产领域结论；② **`gcppos1/2` 不实现**：要 GEPIR（联网授权）才能判，属非目标 → `skipped: gcp_lookup_unavailable`（启 `plan/03` §三）；③ **YY→CCYY 世纪窗口固定在数据文件**（不读时钟，守 K10）。三条都记在 `plan/00` D21 的同一行，此处只作索引。 |
